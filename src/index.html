如何捕获现有系统页面

推荐 方法一：SingleFile 扩展（最完整）

  1. 安装 Chrome 扩展 SingleFile
  2. 在现有系统中打开目标页面
  3. 点击 SingleFile 扩展图标，等待保存完成
  4. 自动下载为单个自包含 HTML 文件
  5. 将多个 HTML 文件打包成 ZIP 上传
跨域CSS全部内联 图片转为内嵌 VPN页面可用 完全离线可用

快速 方法二：页面捕获书签（零安装）

捕获页面 ← 拖到书签栏
  1. 将上方绿色按钮拖拽到浏览器书签栏
  2. 在目标页面点击书签栏的「捕获页面」
  3. 自动下载 HTML 文件
  4. 将多个 HTML 打包成 ZIP 上传
无需安装 VPN页面可用 图片不内嵌 不含动态样式

方法三：浏览器另存为

按 Ctrl+S 保存类型选「网页，完整」，将保存的 HTML 和配套文件夹一起打包成 ZIP。
